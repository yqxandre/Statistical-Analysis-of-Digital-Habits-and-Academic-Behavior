# Statistical-Analysis-of-Digital-Habits-and-Academic-Behavior

This project investigates the factors influencing student productivity using a dataset of
20,000 student records capturing academic habits, lifestyle factors and digital behaviours.

## Objective
- The objective of this project was to model the effect of digital habits, such as phone usage, social media, and gaming on academic productivity.
- A further motivation shifted our focus to examine the underlying generative process of the dataset and show how that affects statistical inference.
